# 群内首次使用指南

机器人首次进入一个已配置的新群时，会自动发送下面这份飞书原生 `post` 富文本。正文正本在 `GroupSummaryService._welcome_guide_text()`，本页用于说明给开发者和群管理员看。

## 群内展示文案

```text
知识库助手・群内使用指南

👋 我会在本群记录作业、复盘和提交时间，并同步到本群独立的打卡表。

✅ 怎么交作业
• “已完成 / 已提交 / 作业提交”都可作为声明；请同时或 10 分钟内发图片、视频、文件、成果链接或完整作品正文。
• 成员不用固定选择 AIGC 或 Coding；特殊排期下按课程内容归入真实任务，旧作业仍回原周期，缓冲日不会把全员标成未交。
• 只有声明没有作品时先记为“待核验”；补上证据后自动改为正常提交或补卡。
• 复盘请带 #复盘；想要文字点评可再加 #求反馈。
• 补交按作业证据的真实发送时间判定；只说“我补交了”不会直接改状态。
• 图片会记录为作业证据，但不识别图片内容。

🔎 @我可以问
• “谁还没交”、“第2次作业”、“前三次作业”
• “查询某人全部打卡记录”、“我的战绩”
• “打开打卡表”、“菜单”

📌 需要我回复时请直接 @知识库助手；普通群聊默认只做记录。

📎 本群打卡表
点击查看打卡表
```

最后一段打卡表只在当前群配置了 `report_link` 时显示，链接来自该群的独立配置，不会串群。

## 触发和去重

- 优先监听 `im.chat.member.bot.added_v1`，机器人进群后立即发送。
- 如果飞书后台漏配入群事件，新群的第一条消息会作为兜底触发。
- 发送后把 `chat_id` 和返回的 `message_id` 写入每群 SQLite 的 `sent_welcome_guides`。
- 相同 `chat_id` 之后再收到事件、重启服务或收到第一条消息，都不再重发。
- 上线时如果 `known_chats` 已有该群，则只写入“已处理”状态，不向已有群补发。
- `SUMMARY_SEND_ENABLED=false` 或群处于 `capture_only` 模式时不发送指南。

## 上线前验收

1. 在飞书开放平台订阅 `im.chat.member.bot.added_v1`，创建新版本并发布。
2. 先为测试群配置独立数据库和群配置，再把机器人加入群。
3. 确认群里只出现一份富文本指南，打卡表链接指向当前群。
4. 重启服务后在群再发一条消息，确认不会再发第二份指南。
